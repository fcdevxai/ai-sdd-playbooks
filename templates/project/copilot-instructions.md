# GitHub Copilot instructions

Read [AGENTS.md](../AGENTS.md) for project context (stack, architecture,
conventions).

This project uses Spec-Driven Development. The SDD skills are installed globally
in `~/.agents/skills/`, the shared target used by GitHub Copilot and Codex. Use
`sdd next` to determine the next valid step; the CLI is the authority on
lifecycle state, not the model. Do not skip steps.
